# App de Notas con TypeScript

Proyecto integrador desarrollado para consolidar los conocimientos de **TypeScript** aplicado a una aplicación web interactiva.

## Características
- **Programación Orientada a Objetos**: Uso de Clases con encapsulamiento (`private`, `readonly`).
- **Contratos de Datos**: Implementación de `Interfaces` para asegurar la estructura de cada nota.
- **Manipulación del DOM**: Renderizado dinámico utilizando `DocumentFragment` para optimizar el rendimiento.
- **Interactividad**: Gestión de eventos mediante `addEventListener` y actualización de estado en tiempo real.

## Tecnologías utilizadas
- **Lenguaje**: TypeScript
- **Entorno**: Vite
- **Estilos**: CSS (Flexbox)

## Cómo ejecutar el proyecto
1. Clonar el repositorio.
2. Instalar dependencias: `npm install`
3. Iniciar servidor: `npm run dev`
